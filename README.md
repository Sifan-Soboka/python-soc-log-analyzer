## Python SOC Log Analyzer

A Python-based defensive security project that analyzes authentication logs and identifies suspicious login activity.

## Objectives

- Parse authentication log entries.
- Detect repeated failed login attempts.
- Identify suspicious authentication patterns.
- Generate readable security reports.
- Test detection rules using synthetic log data.

## Technologies

- Python
- Git and GitHub
- pytest (planned for testing)

## Project Status

Under development.

## Ethical Use

This project is intended for defensive security education and analysis of synthetic or authorized log data.
